# 📄 Installation des dépendances PDF

## ⚠️ Actions requises

Pour que la génération PDF fonctionne, vous devez installer les dépendances suivantes :

### 1. jsPDF (génération PDF)
```bash
npm install jspdf
```

### 2. html2canvas (capture d'images)
```bash
npm install html2canvas
```

### 3. Installation en une seule commande
```bash
npm install jspdf html2canvas
```

## 🚀 Après installation

Une fois les dépendances installées, les fonctionnalités suivantes seront disponibles :

✅ **Emails avec images** (déjà fonctionnel)
- Images intégrées dans les emails HTML
- Version texte avec liens vers les images

✅ **Génération PDF** (après installation)
- PDF avec toutes les informations de l'incident
- Images intégrées dans le PDF
- Mise en page professionnelle
- Téléchargement automatique

## 📝 Utilisation

Le bouton "Générer PDF" apparaîtra dans la table des incidents après l'installation des dépendances.
